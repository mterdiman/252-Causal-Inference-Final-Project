# 252-Causal-Inference-Final-Project
All data and code for our project!

**Methods_Composite_Inference**
This file is stand-alone (allows you to read in data), and computes the ATE via all 3 estimators as well as statistical inference via non-parametric bootstrapping. 

**Data**
This folder contains our data csv (clean_state_data.csv). clean_state_data.R explains where data was sourced from and how it was read in.

**Other files**
Includes SCM file, each estimator's own file, as well as a poisson model run as an extension.
